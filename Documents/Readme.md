# 📑 Documents

This directory contains all essential resources for assembling, wiring, and referencing the Adhyay-1 Robotics Kit.

## Structure

- **Adhyay1_assembled_Images/**  
    Photos and diagrams of a fully assembled Adhyay-1 robot for visual reference.

- **Pinouts/**  
    Pin mapping images and PDFs for every supported microcontroller.

- **Assembly Guide.md**  
    Step-by-step robot assembly instructions.

- **Power_Supply_distribution.png**  
    Schematic diagram showing battery, voltage regulation, and power distribution.

- **Wiring_Adhyay1.pdf**  
    Complete wiring layout for sensors, actuators, and modules for easy connection.

## Usage

- Begin with the Assembly Guide for stepwise construction.
- View Adhyay1_assembled_Images for physical references.
- Use Pinouts before making connections to avoid errors.
- Refer to Power_Supply_distribution.png and Wiring_Adhyay1.pdf for correct wiring.

Contributions and improvements to guides and diagrams are welcome.
