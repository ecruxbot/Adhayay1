#  Pinout References

Here you'll find pin configuration diagrams and PDFs for all supported boards (Pico, ESP32, Nano, STM32).

## Files Included

- **Pin_Reference_Adhyay1.pdf** – Complete pin mapping for all platforms.
- **Pinouts_*.png** – Image diagrams per controller.

## Usage

Always reference these before connecting sensors, actuators, or modules to prevent damage and ensure correct operation.
