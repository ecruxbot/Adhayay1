# Raspberry Pi PicoW Example Projects

The Raspberry Pi PicoW directory includes CircuitPython/MicroPython examples for Adhyay-1 modules.

## Contents

- Bluetooth: Wireless commands and sensor reads
- Buzzer: Tone and alert projects
- DHT 11: Sensing and logging environmental values
- IMU: Movement and orientation demonstrations
- IR_Array: Path detection and line following
- LDR: Ambient light measurements
- Motors: Driving and controlling motors
- OLED Display: Displaying functions and sensor status
- RGB_led: RGB color mixing and effects
- Servo: Precise angular control
- Speaker: Playing sounds, beeps, and music
- Switch: Input state detection
- TSOP: Infrared remote projects
- Ultrasonic Sensor: Multi-sensor distance measurement

## Usage

Open the examples in Thonny, Mu, or another CircuitPython IDE. Make sure Adhyay-1 libraries on the SD card are loaded for full functionality. Reference wiring guides before connecting hardware.
