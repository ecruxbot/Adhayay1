# ESP32 Example Projects

This folder contains projects for the ESP32 controller. Individual directories demonstrate each Adhyay-1 module and sensor.

## Contents

- Bluetooth: Wireless control and communication
- Buzzer: Sound and alert generation
- DHT 11: Reading temperature and humidity values
- IMU: Motion sensing with the MPU6050
- IR_Array: Line following sensor integration
- LDR: Light sensor usage
- Motors: DC motor control for robotics
- OLED Display: Visual output and sensor data display
- RGB_Led: Color LED control projects
- Servo: Angular control for robotics
- Speaker: Audio and tone generation
- Switch: Reading button states
- TSOP: IR receiver for remote functionality
- Ultrasonic Sensor: Distance and object detection

## Usage

Transfer ESP32 examples to your development environment. Confirm pin connections as shown in kit documentation before running sample codes.
