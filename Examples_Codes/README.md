# Example Codes

This folder contains sample codes for all microcontroller platforms supported by the Adhyay-1 robotics kit.

## Subdirectories

- Arduino_nano
- Esp32
- Raspberry Pi PicoW
- STM_32

Each subfolder includes example code to demonstrate the use of various sensors, actuators, wireless interfaces, and robotics functions with Adhyay-1 hardware.

## Usage

Browse the folder for your specific microcontroller. Start with basic single-module examples and progress towards more integrated projects as your skills advance. Refer to the documentation for wiring and setup guidance.
