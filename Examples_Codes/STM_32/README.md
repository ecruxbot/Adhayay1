# STM32 Example Projects

Sample codes for the STM32 microcontroller will provided in this folder. Those will examples show how to interface Adhyay-1 modules using STM32 IDEs and library support.

## Contents

Contains basic interfacing for switches, sensors, motors, and other kit components. More advanced projects will be added in future updates.

## Usage

Import these examples into your STM32 development software. Connect your hardware according to the kit's pinout and wiring documentation.
