# Arduino Nano Example Projects

The Arduino_nano directory features sample projects for the Arduino Nano and Nano 33 BLE Sense boards. Each hardware module has a dedicated folder containing example code.

## Contents

- 5-CH_IR: Line following sensor examples
- BLUETOOTH: Remote control and wireless communication
- BUZZER: Buzzer control and sound alerts
- DHT-11: Temperature and humidity monitoring
- LDR: Light sensor interfacing
- MPU-6050: Motion and orientation detection
- Motors: DC motor drive examples
- OLED: Display output for sensor data
- RGB: Color LED projects
- SERVO: Control of servo motors
- SPEAKER: Generating sounds and tones
- SWITCH: Reading digital inputs
- TSOP: IR remote and receiver demonstrations
- ULTRASONIC: Distance measurements

## Usage

Copy examples to the Arduino IDE. Connect hardware as described in wiring guides, and upload the code to get started with each module.
